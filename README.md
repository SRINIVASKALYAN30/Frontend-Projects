<h2>🚀 Projects</h2>

<h3>🔳 1. QR Generator</h3>

<p>
The <strong>QR Generator</strong> is a simple web application that allows
users to generate QR codes from text, URLs, or other input data.
</p>

<p>
The application provides a clean interface where users can enter their
desired content and generate a QR code dynamically.
</p>

<h4>✨ Features</h4>

<ul>
<li>Generate QR codes dynamically</li>
<li>Accept text and URLs as input</li>
<li>Simple and user-friendly interface</li>
<li>Fast QR code generation</li>
<li>Responsive design</li>
<li>Works directly in the browser</li>
</ul>

<h3>🐍 2. Snake Game</h3>

<p>
The <strong>Snake Game</strong> is a browser-based implementation of the
classic Snake game built using HTML, CSS, and JavaScript.
</p>

<p>
The player controls the snake using keyboard controls, collects food,
increases the snake's length, and tries to achieve the highest possible
score without colliding with the walls or the snake itself.
</p>

<h4>✨ Features</h4>

<ul>
<li>Classic Snake gameplay</li>
<li>Keyboard-based controls</li>
<li>Dynamic snake movement</li>
<li>Food generation</li>
<li>Score tracking</li>
<li>Collision detection</li>
<li>Game-over functionality</li>
<li>Responsive and simple interface</li>
</ul>

<h3>🎨 3. Drawing App</h3>

<p>
The <strong>Drawing App</strong> is an interactive browser-based drawing
application that allows users to draw directly on a digital canvas.
</p>

<p>
The application uses the browser's <strong>Canvas API</strong> to provide
a simple drawing environment where users can create sketches and drawings
using their mouse or pointer.
</p>

<h4>✨ Features</h4>

<ul>
<li>Draw directly on the canvas</li>
<li>Interactive drawing experience</li>
<li>Mouse and pointer interaction</li>
<li>Canvas-based rendering</li>
<li>Simple and clean interface</li>
<li>Responsive design</li>
<li>Real-time drawing</li>
</ul>
