<h2>📌 About This Repository</h2>

<p>
<strong>Frontend Projects</strong> is a collection of interactive and
beginner-friendly web applications developed using
<strong>HTML, CSS, and JavaScript</strong>.
</p>

<p>
This repository contains multiple projects created to practice and
demonstrate practical frontend development concepts, including
<strong>responsive design, JavaScript logic, DOM manipulation,
event handling, user interaction, and dynamic content updates</strong>.

experience in building functional and visually appealing web applications
from scratch.

<h2>🔳 QR Generator</h2>

<h3>📖 Description</h3>

<p>
The <strong>QR Generator</strong> is a lightweight web application
designed to generate QR codes from user-provided information.
Users can enter text, URLs, or other supported data and generate
a corresponding QR code instantly.
</p>

<h3>✨ Key Features</h3>

<ul>
<li>🔗 Generate QR codes from URLs and text</li>
<li>⚡ Fast and interactive generation</li>
<li>🎨 Simple and clean user interface</li>
<li>📱 Responsive design</li>
<li>🖱️ Easy-to-use controls</li>
<li>💻 Runs directly in the browser</li>
</ul>

<h3>🛠️ Technologies</h3>

<p>
<code>HTML5</code>
<code>CSS3</code>
<code>JavaScript</code>
</p>

<h2>🐍 Snake Game</h2>

<h3>📖 Description</h3>

<p>
The <strong>Snake Game</strong> is a web-based recreation of the
classic arcade game. The player controls a continuously moving snake
and must collect food to increase the score and the length of the snake.
</p>

<p>
The game becomes progressively challenging as the snake grows.
The player must avoid collisions with the game boundaries and
the snake's own body.
</p>

<h3>✨ Key Features</h3>

<ul>
<li>🐍 Classic Snake gameplay</li>
<li>🎮 Keyboard-based controls</li>
<li>🍎 Food generation</li>
<li>📈 Dynamic score tracking</li>
<li>💥 Collision detection</li>
<li>🔄 Game restart functionality</li>
<li>📱 Responsive game interface</li>
</ul>

<h3>🛠️ Technologies</h3>

<p>
<code>HTML5</code>
<code>CSS3</code>
<code>JavaScript</code>
</p>

<h2>🎨 Drawing App</h2>

<h3>📖 Description</h3>

<p>
The <strong>Drawing App</strong> is an interactive browser-based
application that allows users to draw directly on a digital canvas.
</p>

<p>
The project demonstrates how JavaScript can interact with the
<strong>HTML Canvas API</strong> to create real-time drawing
experiences within a web browser.
</p>

<h3>✨ Key Features</h3>

<ul>
<li>🎨 Freehand drawing</li>
<li>🖱️ Mouse-based drawing interaction</li>
<li>🖌️ Canvas-based rendering</li>
<li>⚡ Real-time drawing</li>
<li>🧹 Interactive controls</li>
<li>📱 Responsive interface</li>
</ul>

<h3>🛠️ Technologies</h3>

<p>
<code>HTML5</code>
<code>CSS3</code>
<code>JavaScript</code>
<code>Canvas API</code>
</p>
